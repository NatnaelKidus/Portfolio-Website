# My Portfolio Website

# Website Description
This portfolio was created for my Web and Scripting Programming class. It showcases my background, programming projects, and contact information using HTML5 and CSS3.

# Website Structure
The website consists of four HTML pages:

- Home (`index.html`): Introduction and website navigation.
- About Me (`about.html`): Personal biography, photograph, and introductory video.
- Projects (`projects.html`): Four programming and networking projects.
- Contact Me (`contact.html`): Contact form with HTML5 validation.

# Responsive Design
The website uses fluid layouts and three separate CSS files to support different screen sizes:

Mobile | 0–599px | `mobile.css` |
Tablet | 600–1023px | `tablet.css` |
Desktop | 1024px and above | `desktop.css` |

These breakpoints were chosen to accommodate smaller phone screens, medium-sized tablets, and larger desktop displays. The `base.css` file contains the shared styling. The layout uses percentages, floats, and inline-block elements

# Color Scheme
The website uses the **Spring Forward** color palette, inspired by Davey & Krista's website color palette collection.

- Emerald Green: `#23645C`
- Sage Green: `#879681`
- Warm Gold: `#BC984E`
- Cream: `#ECE6D9`
- Charcoal: `#33312E`

The green shades are used for headers and navigation, gold for accents, cream for backgrounds, and charcoal for text.

# CSS Gradients
Two types of linear gradients are used:

- Angled linear gradient: Applied to the page headers and homepage banner.
- Directional linear gradient: Applied to the contact form's Submit button.

# Testing and Validation
The website will be tested using:

- W3C HTML Validator
- W3C CSS Validator
- W3C Link Checker
- WAVE Accessibility Evaluation Tool
- Browser spelling check and responsive device testing

Link Validation: Tested using the W3C Link Checker. All HTTP/HTTPS links passed. The mailto: email link was skipped by the validator because email URL checking is disabled. The email link was tested manually.
